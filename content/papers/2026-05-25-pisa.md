## 研究问题

视觉扩散 Transformer 的 token 数随空间分辨率和视频长度增长，完整 self-attention 成为主要瓶颈。已有局部窗口容易失去全局可见性，训练型稀疏方案又提高迁移成本；PISA 追求无需重新训练、能直接加到现有 DiT 的近似 attention。

## 核心方法

- 将 layers/blocks 分成关键与非关键部分：敏感位置继续做 exact attention，冗余位置才替换为近似计算。
- 对非关键 blocks 进行 block-wise Taylor approximation，以较低成本近似 softmax attention。
- 块划分仍覆盖完整 token span，因此与纯局部窗口相比保留全局信息通道。
- 这是推理期替换，不需要为每个基础模型再训练一个稀疏模块。

标准 attention 为

$$
\operatorname{Attn}(Q,K,V)
=\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt d}\right)V.
$$

PISA 的核心不是删除全局 token，而是在非关键位置近似指数核及其归一化，同时把误差预算留给更敏感的 blocks。

## 关键发现

- 历史记录中的结果：Wan2.1-14B 推理约 **1.91×**，HunyuanVideo 约 **2.57×**，FLUX.1 约 **2×** 加速。
- 当时公开仓库主要是 Triton kernel 与 FLUX demo；其他模型脚本尚不完整，因此论文数字不等于开箱即用的通用支持。

## 我的提问

### Q1：PISA 和 RTPurbo 哪个更适合先用于 LTX-2.3？

PISA 更像第一步：它不需要 post-training，且直接针对视觉 DiT 的时空 attention。RTPurbo 的动态稀疏更灵活，但索引器和 LLM 假设迁移成本更高。

### Q2：LTX-2.3 中哪些 attention 应该先替换？

优先高 token 数的视频 self-attention；audio、text cross-attention 以及已知对语义敏感的 blocks 先保留精确计算。逐层做误差和质量消融，不要只以理论 FLOPs 决定替换范围。

## 局限与疑问

- training-free 不代表无校准：关键 block、块大小和近似阶数仍需针对模型与分辨率选择。
- Triton kernel 的形状约束和内存访问决定真实速度，PyTorch 原型的 FLOPs 优势可能无法兑现。
- 长视频的时间一致性可能比静态图像指标更早暴露近似误差。

## 我的判断

这是更适合快速工程验证的视频 attention 加速路线。先在单一 self-attention 路径上做可回退实现，并按分辨率记录端到端 latency；只有高质量设置仍有稳定收益时，再扩展到更多 blocks。

## 下次只看这些

1. 关键 blocks 精确，非关键 blocks 才做 Taylor 近似。
2. 全局 span 仍被覆盖，区别于只看局部窗口。
3. 对 LTX-2.3 先动视频 self-attention，条件 attention 保持 dense。
